Device Description      The Boston Scientific WATCHMAN FXD Curve™ Access
                        System is composed of an Access Sheath and Dilator. The
                        WATCHMAN FXD Curve Access System is used to provide
                        vascular and transseptal access for WATCHMAN™ FLX™ Left
                        Atrial Appendage Closure Device with Delivery System. The
                        WATCHMAN FXD Curve Access System will be used by
                        interventional cardiologists and/or electrophysiologists who are
                        trained in percutaneous and transseptal procedures.

Indications for Use /   The WATCHMAN FXD Curve™ Access System is intended to
Intended Use            provide vascular and transseptal access for the WATCHMAN™
                        FLX™ Left Atrial Appendage Closure Device with Delivery
                        System.
